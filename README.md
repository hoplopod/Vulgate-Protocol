Vulgate protocol – это учебный проект с закосом за механики из “Sekiro: Shadows Die Twice” в 2D с использованием библиотеки Spine.
Игрок находится на дуэли с мечником Baptist’ом и ему предстоит с помощью парирований и блоков победить его.
Боевая система:
1. ПКМ – блок (блокирует любую атаку, если попасть в нужный тайминг)
2. ЛКМ – атака (в зависимости от положения лезвия в руке парирует с последующим станом врага, если попасть по его оружию во время его атаки)
3. СКМ – атака колющая (не парирует, только наносит урон)
4. Пробел – смена положения лезвия

Игрок должен попасть по оружию врага во время его удара в сопутствующем положение (нижняя -  лезвие игрока снизу и верхняя – лезвие игрока сверху, атака врага по середине не контратакуется) и после удачной контратаки нанести любой удар по оглушённому врагу, в любом другом случае атака игрока будет заблокирована.
